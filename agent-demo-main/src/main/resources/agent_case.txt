使用方式类

赋属性工具
问题：如何使用赋属性这个功能？
答案：步骤一:选择写入属性以及客户标准
        注意用户标准选择
   步骤二:选择零件
       选择扫描则自动寻找已排序工件
   步骤三:零件编码排序
       检查客户标准
   步骤四:主视图方向
       按需选取俯视图或仰视图
   步骤五:原点方向规则，默认以长直边短直边为零边，长度默认400为大板分界，亦可自定义
     勾选规则1 则指定所选颜色为零边，3D要对应涂色
     勾选规则2则自定义长短边比例，如长宽比10:1为长条形工件，原点位 置可设置是四面分中或左下角
chunk_id：785df2b7b57a4d07b6e0c78b58936da8，3eb7858e33934e2683bc8a0a825c1c52

BOM工具
问题：如何使用BOM表工具这个功能？
答案：步骤一:填写并检查客户信息、模号、产品编号
   步骤二:选择BOM表类型
   步骤三:按需勾选已备料不出料单，是否分页，设置分页类型和行数
   步骤四:扫描所有实体出BOM表或者选择实体生成
   步骤五:点击导出EXCEL。导出EXCEL后如有需要可以点击EXCEL转TXT文本
chunk_id：51af564fd41e40d0bf77c03d6cf6f0e0

建模出图工具
问题：如何使用建模出图工具这个功能？
答案：步骤一:填写模具编号
     步骤二:选择要出图的零件（按需选择常规或轻量化视图）
     步骤三:选择第三或第一视角
     步骤四:选择视图，按需勾选球标图、线割涂色、研磨符号
     步骤五:设置球标大小，按需勾选加工说明、英文注解、英制牙，选择做深/掏留，选择槽注解，填写图纸路径
     步骤六:填写对应的信息后确定
     步骤八:待出图完毕后打开图纸路径查看图纸
chunk_id：bd2614db48074c9e9a420af8bedd404a，c3562f9d5ffd40f18c73d7b649b86b1d
