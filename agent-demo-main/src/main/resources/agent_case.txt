使用方式类

赋属性
问题：如何使用赋属性这个功能？
答案：步骤一:选择写入属性以及客户标准
        注意用户标准选择
   步骤二:选择零件
       选择扫描则自动寻找已排序工件
   步骤三:零件编码排序
       检查客户标准
   步骤四:主视图方向
       按需选取俯视图或仰视图
   步骤五:原点方向规则，默认以长直边短直边为零边，长度默认400为大板分界，亦可自定义
     勾选规则1 则指定所选颜色为零边，3D要对应涂色
     勾选规则2则自定义长短边比例，如长宽比10:1为长条形工件，原点位 置可设置是四面分中或左下角
chunk_id：785df2b7b57a4d07b6e0c78b58936da8，3eb7858e33934e2683bc8a0a825c1c52

快速涂色赋注解
问题：如何使用快速涂色赋注解这个功能？
答案：步骤一：选择设计标准
        根据客户选择设计标准。
   步骤二：选体分析
        设置大板是否注解槽，框选多个实体进行分析注释。
   步骤三：上色
        根据材质推荐色给孔上色。
   步骤四：修改、添加注解
        选面添加注解，点击注释在文本框修改内容。
